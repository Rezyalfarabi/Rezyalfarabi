## Tentang saya

Saya Rezy, orang yang lebih sering ditemukan di depan editor kode daripada di tempat lain. Awalnya iseng bikin halaman HTML, sekarang sudah merembet ke PHP, Flutter, sampai urusan database.

Beberapa hal yang lagi saya kerjakan dan pelajari:

- Membangun website dengan HTML, CSS, JavaScript, dan PHP
- Bikin aplikasi mobile pakai Flutter dan Dart
- Belajar bikin backend yang rapi dengan Supabase dan MySQL
- Membiasakan commit kecil-kecil biar riwayat Git tidak berantakan

Fakta kecil: bug paling lama yang pernah saya cari ternyata cuma salah ketik satu huruf. Sejak itu saya percaya bahwa titik koma punya kekuatan.

Beberapa kebenaran pahit dunia ngoding:

- Kode yang "cuma diubah sedikit" hampir selalu bikin sesuatu yang lain rusak.
- Fitur yang jalan di laptop belum tentu jalan setelah deploy.
- `git commit -m "fix"` adalah pesan commit paling jujur sekaligus paling tidak membantu.
- Flutter hot reload bikin ketagihan, dan sulit balik ke cara lama.
